# ViraCarta

Mini game mobile de flashcards baseado no baralho **“Isso é bom ou ruim?”**.

## Como jogar

1. Leia uma proposta e marque se considera **boa** ou **ruim**.
2. Tente adivinhar se a frase é atribuída a **Lula** ou **Flávio Bolsonaro**.
3. Vire a carta, confira a resposta e avance pelas 32 cartas.

O jogo embaralha as cartas, registra acertos, mostra o progresso e pode ser instalado na tela inicial do celular. As frases e atribuições seguem o PDF fornecido; o jogo não indica em quem votar.

## Tecnologia

HTML, CSS e JavaScript puros, sem dependências. Funciona como PWA e também offline após o primeiro acesso.
